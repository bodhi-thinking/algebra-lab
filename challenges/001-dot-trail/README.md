# Challenge 1 — The Dot Trail

## Learner task

The pattern keeps growing. How many dots will there be in Step 10?

## Challenge visual

The original `assets/pattern.jpg` is retained as the visual reference. The learner-facing visual is rendered by `this challenge folder (`ChallengeVisual.tsx`)` so the figures can rearrange responsively on mobile.

The visual is independent from Lab state. Editing the Lab never changes the challenge figures or question.

## Algebra Lab starting point

The Lab opens with:

```text
y = x
```

The starting state is configured in `challenge.ts`.
