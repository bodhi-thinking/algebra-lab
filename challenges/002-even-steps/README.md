# Challenge 2 — Even Steps

## Learner-facing prompt

> You found the pattern in the last one. Let’s change it up! Can you figure out how many dots there will be at Step 10?

## Hints

1. How many dots are added each time?
2. This time, 2 dots are added at every step.
3. Start with 2 and keep adding 2 until Step 10.

## Answer

20 dots.

## Pattern

2, 4, 6, 8, 10, 12, …

Each step adds 2 dots.

## Lab initialization

The Lab starts with `y = 2x`, using Steps 1–7 (6 jumps), so the visible outputs are 2, 4, 6, 8, 10, 12, 14.

The challenge visual is independent of Lab state.
