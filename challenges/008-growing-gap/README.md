# Challenge 08 — The Growing Gap

## Mathematical focus

Compare two linear patterns and investigate how the difference between them changes from figure to figure.

- Pattern A: 8, 12, 16, 20, 24, …
- Pattern B: 8, 16, 24, 32, 40, …
- Gap B − A: 0, 4, 8, 12, 16, …
- Rate of growth of the gap: +4 blocks per figure.

## Pedagogical intent

Challenge 7 establishes that the two patterns grow at different rates.

Challenge 8 shifts attention to the relationship between the patterns. The learner is prompted to inspect the number line and graph, notice the changing gap, and identify its rate.

The equation representation is available but is not named in the scored question. The follow-up invites the learner to connect the discovered rate to the equations.

## Representation setup

All four Lab representations remain enabled:

- Number line
- Algebra tiles
- Graph
- Equation

The challenge does not allow adding extra equations.

## Expected answer

`4`

## Follow-up

"Now change the lens. Can you find that same 4 hiding in the equations?"
